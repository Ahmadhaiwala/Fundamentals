# Maximum Points You Can Obtain from Cards

## Approach

We need to take exactly `k` cards, and every card must come from either the **left end or right end**.

Instead of thinking about which `k` cards to take, think about the cards we **leave behind**.

If:

```text
n = len(cardPoints)
```

then the number of cards left behind is:

```text
n - k
```

These cards will always form a **continuous middle subarray**.

So:

```text
Maximum score
= Total sum - Minimum sum of a window of size (n - k)
```

This becomes a fixed-size **Sliding Window** problem.

### Steps

1. Calculate the total sum of the array.
2. Calculate `window_size = n - k`.
3. Find the minimum sum of any continuous window of size `window_size`.
4. Return:

```text
total - minimum_window_sum
```

---

## Dry Run 1

```text
cardPoints = [1, 2, 3, 4, 5, 6, 1]
k = 3
```

```text
n = 7
window_size = 7 - 3 = 4
```

Total:

```text
1 + 2 + 3 + 4 + 5 + 6 + 1 = 22
```

Now find the minimum window of size `4`.

```text
[1, 2, 3, 4] → 10
[2, 3, 4, 5] → 14
[3, 4, 5, 6] → 18
[4, 5, 6, 1] → 16
```

Minimum window:

```text
10
```

Therefore:

```text
answer = 22 - 10
       = 12
```

The selected cards are:

```text
5 + 6 + 1 = 12
```

## Code

```python
class Solution:
    def maxScore(self, cardPoints: list[int], k: int) -> int:
        total = sum(cardPoints)

        window_size = len(cardPoints) - k

        current_window_sum = sum(cardPoints[:window_size])
        min_window_sum = current_window_sum

        for i in range(window_size, len(cardPoints)):
            current_window_sum += (
                cardPoints[i] - cardPoints[i - window_size]
            )

            min_window_sum = min(
                min_window_sum,
                current_window_sum
            )

        return total - min_window_sum
```

## Key Idea to Remember

When you see:

> Take `k` elements from the **ends**

Think:

```text
What am I leaving behind?
        ↓
n - k continuous elements
        ↓
Find minimum fixed-size window
        ↓
total - minimum window
```

This is the important Sliding Window pattern.
